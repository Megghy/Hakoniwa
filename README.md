# 箱庭工坊 (Project Hakoniwa)

> **Hakoniwa** 是一个专为 **Terraria** 玩家与地图创作者设计的次世代内置箱庭构筑与地图编辑工具套件。
> 突破常规游戏限制，将建筑创造力从枯燥繁琐的操作中解放出来。

---

## 核心特性一览

- 📦 **切块与蓝图系统 (Schematics)**
  - 自由选取、复制、粘贴、翻转、旋转世界物块。
  - 标准化二进制压缩蓝图格式（`.schem`），极速导入导出与搜索归档。
  - 半透明幽灵物块投影预览，精准对齐像素坐标。

- 🖌️ **智能画笔与几何地形工具 (Tool Engine)**
  - 多样化笔刷：圆形、方形、菱形、平滑过渡，支持动态尺寸与离散度调节。
  - 连通域洪水填充（Flood Fill），支持同类物块精准替换与遮罩（Masking）。
  - 范围橡皮擦、图层过滤（仅物块/仅墙壁/仅电线/仅涂漆）。

- ⚡ **无界建造与自由法则 (Restriction Bypass)**
  - 全图无限制交互与放置距离（Infinite Reach）。
  - 穿墙放置、浮空放置与非法物块形态强行安置。
  - 无限物块与道具不消耗机制，无需反复背包备料。

- 🛸 **空间瞬移与微观洞察 (Spatial & Vision)**
  - 视口自由穿梭与全图瞬移。
  - 全图照明与高亮透视，排除阴影与光照遮挡。

- 🎨 **Dear ImGui 现代化界面与沉浸式双层渲染**
  - 即时模式 UI，支持自由浮动、折叠、多窗口停靠与暗色调定制二次元主题。
  - 世界空间像素级对齐渲染（SpriteBatch 投影），所见即所得。

## 项目架构与工程组织

采用 **KISS 单项目架构**，单一可执行文件产物，内部按清晰命名空间分层：

```text
Hakoniwa/
├── src/
│   ├── Hakoniwa.csproj      # 唯一工程文件 (WinExe, net48 + C# 13)
│   ├── Program.cs           # 启动器入口与引导
│   ├── Core/                # MonoMod Hook 运行时与游戏限制解除
│   ├── Engine/              # 选区快照、几何变换、笔刷与蓝图序列化引擎
│   └── UI/                  # Dear ImGui 交互面板与世界投影画布
├── dev-docs/                # [GitIgnored] 内部开发路线、Hook 契约与技术规格
├── ARCHITECTURE.md          # 系统架构与设计决策
└── Directory.Build.props    # 现代 SDK-Style + net48 + C# 13 + PolySharp
```
