# Hakoniwa (箱庭工坊)

Hakoniwa 是基于 MonoMod 与 Dear ImGui 构建的 Terraria (1.4.5.8) 内置地图编辑与建造辅助工具。项目以单一可执行程序（`Hakoniwa.exe`）的形式运行，在保持游戏原生运行时的同时，提供游戏内地图像素级选区编辑、蓝图序列化导入导出、几何笔刷、世界规则调试与资产管理能力。

---

## 功能特性

### 1. 选区与蓝图系统 (Selection & Schematics)
- **空间选区**：支持世界坐标的矩形选区划定，提供复制、剪切、粘贴、90°/180°/270° 旋转及水平/垂直镜像翻转。
- **蓝图序列化 (`.schem`)**：采用紧凑值类型结构（`TileDataBlock`）与 Zstd 压缩存储，支持物块、墙壁、液体、电线、涂漆以及箱子、标牌、TileEntity 等附加数据的完整导出与导入。
- **幽灵预览**：粘贴与蓝图放置时提供半透明幽灵物块（Ghost Tile）对齐投影，所见即所得。

### 2. 几何笔刷与地形编辑 (Tool Engine)
- **多样化笔刷**：提供矩形、圆形、菱形笔刷，支持动态半径与离散度调节。
- **几何形状绘制**：支持直线、矩形框/填充、椭圆框/填充等基础几何形态的快速构建。
- **连通域与遮罩填充**：提供连通域洪水填充（Flood Fill）与指定物块类型的定向替换（Masking Replace）。
- **图层过滤**：支持独立过滤物块（Tile）、墙壁（Wall）、电线（Wire）、液体（Liquid）与涂漆（Paint）。
- **历史撤销栈**：基于 `HistoryStack` 的多步撤销（Undo）与重做（Redo），支持单次笔刷连续涂抹的自动聚合。

### 3. 建造辅助与规则控制 (Rules & Cheats)
- **放置与交互**：解除全图放置距离与交互达距限制，支持穿墙放置与浮空物块安置。
- **资源保护**：支持物块与消耗性道具免消耗。
- **状态与视野**：支持穿墙飞行（Noclip）、无敌状态以及全图高亮照明（Fullbright）。

### 4. 世界与环境管理 (World Management)
- **环境控制**：时间冻结/快进、天气切换（下雨、风向与风速）。
- **事件管理**：支持血月、日食、南瓜月、霜月等世界事件的手动开启与关闭。
- **实体与进度**：城镇 NPC 生成与重置、全 Boss 击杀标记切换。
- **空间传送**：支持出生点重设、大地图右键传送与世界视野中键快速传送。

### 5. 物品与背包管理 (Item & Inventory)
- **物品检索与获取**：对齐原版 Creative 分类标准的全物品目录检索与快速拾取。
- **背包快照方案**：支持多页背包命名快照的保存、切换与管理。
- **属性配置**：支持对手持物品的基础数值进行调整。

### 6. 游戏内交互与文本增强 (Native Input & IME)
- **输入框增强**：针对原版聊天栏、标牌与箱子命名输入框，补充光标定位、鼠标划词拖选、剪贴板交互、撤销/重做与中英文词边界分词。
- **IME 支持**：独立的输入法候选框浮层渲染，自动适配光标位置与屏幕边界。

## 技术架构

```text
Hakoniwa/
├── src/
│   ├── Hakoniwa.csproj      # 唯一运行时工程 (WinExe, net48 + C# latest + PolySharp)
│   ├── Program.cs           # 进程引导与全局异常捕获
│   ├── set-laa.ps1          # 构建后 Large Address Aware 配置脚本
│   ├── Core/                # MonoMod Hook 生命周期、规则注入、世界读写与文本增强
│   ├── Engine/              # 选区快照、几何算法、变换矩阵与 .schem 序列化
│   └── UI/                  # Hexa.NET.ImGui 渲染管线、世界投影与工坊窗口
├── tests/Hakoniwa.Tests/    # 单元测试工程（覆盖序列化、工具算法与 Hook 基础设施）
├── libs/                    # 依赖的原版程序集引用 (ReLogic.dll)
├── ARCHITECTURE.md          # 架构详细设计文档
└── Directory.Build.props    # 统一编译参数配置
```

- **单程序集无缝集成**：编译输出单一 `Hakoniwa.exe`，不额外分发运行时 DLL，避免加载与依赖解析冲突。
- **Publicizer 编译期全量暴露**：使用 `BepInEx.AssemblyPublicizer.MSBuild` 在编译期公开 `Terraria.exe` 全部内部成员，直接调用底层状态，零反射损耗。
- **双层渲染管线**：
  - **GUI 交互层**：采用 `Hexa.NET.ImGui` (Dear ImGui) 即时模式渲染工坊主界面、工具栏与悬浮入口。
  - **世界投影层**：直接复用 XNA 原生 `SpriteBatch`，实现选区指示器、笔刷准星与幽灵物块的像素级对齐。
- **4GB 虚拟内存支持**：构建阶段自动配置 Large Address Aware (LAA)，避免 32 位进程在加载大规模世界资产时发生内存溢出（OOM）。

## 常用操作与快捷键

| 按键 / 操作 | 功能说明 |
|---|---|
| `Insert` | 打开 / 隐藏 Hakoniwa 工坊主窗口 |
| `大地图右键` / `世界中键` | 快速瞬移至目标坐标 |
| `Ctrl + 鼠标滚轮` | 调整当前笔刷尺寸与几何形状大小 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销（Undo） / 重做（Redo）编辑操作 |
| `Shift + 左键拖动` | 划定选区范围 |
| `Ctrl + C` / `Ctrl + V` | 复制选区 / 进入粘贴预览状态 |

## 编译与运行

### 环境要求
- .NET 8.0 SDK 或更高版本（用于驱动 MSBuild）
- 已安装 Steam 原版 Terraria (1.4.5.8)

### 构建步骤
```powershell
# 编译解决方案（输出目录默认指向 Steam 的 Terraria 安装路径）
dotnet build Hakoniwa.slnx

# 执行单元测试
dotnet test Hakoniwa.slnx
```

### 运行说明
构建完成后，直接运行游戏目录下的 **`Hakoniwa.exe`** 即可启动已挂入工具链的 Terraria 进程。
